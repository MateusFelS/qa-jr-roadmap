# Checklist de Testes

Um **checklist de testes** é uma lista de verificações usada para validar um sistema de forma rápida e consistente.

Segundo o ISTQB:

> "Checklist-based testing é uma técnica baseada na experiência, usando uma lista de itens a verificar."

---

## Objetivo

- Garantir cobertura básica
- Evitar esquecimentos
- Padronizar testes
- Apoiar testes exploratórios e regressão

---

## Checklist vs Caso de Teste

- **Caso de teste** → detalhado, passo a passo  
- **Checklist** → simples, direto, rápido  

---

## Estrutura

| Campo | Descrição |
|------|----------|
| ID | Identificador |
| Item | O que verificar |
| Status | OK / NOK |
| Observações | Notas ou problemas |

---

## Tipos de Checklist

- **Funcional** → funcionalidades funcionando  
- **UI** → layout e usabilidade  
- **Validação** → regras de entrada  
- **Regressão** → nada quebrou após mudanças  

---

## Boas Práticas

- Ser **simples e direto**
- Baseado em **experiência**
- Ser **enxuto** (sem excesso)
- **Reutilizável**
- **Atualizado com bugs encontrados**

---

## Quando Usar

- Testes exploratórios  
- Smoke tests  
- Regressão  
- Pouco tempo disponível  

---

## Erros Comuns

- Muito genérico  
- Muito detalhado (vira caso de teste)  
- Ambíguo  
- Não atualizar  

---

## Relação com Outras Técnicas

- Teste exploratório  
- Error guessing  
- Teste baseado em risco
