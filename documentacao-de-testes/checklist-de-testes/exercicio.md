# Exercício – Criação de Checklist de Testes

## Contexto

Sistema de **cadastro de usuário** com as seguintes regras:

- Nome é obrigatório
- E-mail deve ter formato válido
- Senha deve ter no mínimo 8 caracteres
- Confirmação de senha deve ser igual à senha
- Sistema deve exibir mensagens de erro claras
- Cadastro bem-sucedido redireciona para tela de login

---

## Tarefa

👉 Crie um **checklist de testes** contendo:

- ID  
- Item  
- (Opcional) Observações  

⚠️ Não é necessário detalhar passos — apenas o que deve ser verificado.

---

## Pontos que devem ser cobertos

| ID | Categoria | Descrição |
|----|----------|----------|
| CEN-01 | Funcional | Cadastro com dados válidos |
| CEN-02 | Validação | Campos obrigatórios |
| CEN-03 | Validação | Formato de e-mail |
| CEN-04 | Validação | Regra de senha mínima |
| CEN-05 | Validação | Confirmação de senha |
| CEN-06 | Feedback | Mensagens de erro |
| CEN-07 | Fluxo | Redirecionamento após sucesso |
| CEN-08 | UI | Elementos visuais básicos |
