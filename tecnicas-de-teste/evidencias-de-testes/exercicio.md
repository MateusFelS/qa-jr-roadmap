# Exercício – Evidências de Teste

## Contexto

Foi executado o seguinte caso de teste:

**CT-LOGIN-001**

Objetivo:
Validar login com usuário e senha válidos.

Passos:
1. Acessar tela de login
2. Informar usuário válido
3. Informar senha válida
4. Clicar em Entrar

Resultado esperado:
Sistema deve direcionar para a página inicial.

👉 Identifique quais evidências devem ser coletadas para comprovar a execução do teste.

---

## Resolução

### Evidências Recomendadas

| ID | Evidência | Objetivo |
|----|-----------|----------|
| EV-01 | Captura da tela de login preenchida | Demonstrar dados utilizados |
| EV-02 | Captura da página inicial após login | Comprovar resultado esperado |
| EV-03 | Data e horário da execução | Garantir rastreabilidade |
| EV-04 | Identificação do ambiente | Informar contexto da execução |
| EV-05 | Registro do executor | Identificar responsável |

### Resultado

As evidências apresentadas permitem demonstrar:

- O que foi testado
- Como foi testado
- Quem executou
- Quando ocorreu a execução
- Qual foi o resultado obtido
