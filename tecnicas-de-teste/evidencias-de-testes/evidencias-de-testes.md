# Evidências de Teste

As **Evidências de Teste** são registros produzidos durante a execução dos testes com o objetivo de demonstrar que uma determinada ação foi realizada e qual foi seu resultado.

Segundo o ISTQB, evidências são fundamentais para garantir rastreabilidade, auditoria e suporte à análise de defeitos.

Conforme **Elfriede Dustin** (em *Effective Software Testing*):

> "Um defeito sem evidência adequada é frequentemente difícil de reproduzir, validar ou corrigir."

---

## Conceito Fundamental

Uma evidência de teste deve permitir que outra pessoa consiga compreender:

- O que foi testado.
- Como foi testado.
- Qual resultado foi obtido.
- Em qual ambiente ocorreu o teste.

---

## Tipos de Evidências

| Tipo | Exemplo |
|--------|---------|
| Captura de tela | Screenshot da aplicação |
| Vídeo | Gravação da execução |
| Log de sistema | Registro técnico da operação |
| Arquivo gerado | PDF, planilha ou relatório produzido |
| Banco de dados | Consulta demonstrando resultado |

---

## Características de uma Boa Evidência

Uma evidência deve ser:

| Característica | Descrição |
|----------------|-----------|
| Clara | Fácil de entender |
| Completa | Contém informações suficientes |
| Reproduzível | Permite validar o resultado |
| Rastreável | Relacionada ao caso de teste |
| Armazenável | Disponível para consultas futuras |

---

## Exemplo Prático

**Caso de teste:** Validar login com usuário válido.

**Evidência anexada:**

- Captura da tela de login.
- Captura da mensagem de sucesso.
- Registro da data e horário da execução.
- Identificação do ambiente utilizado.

---

## Benefícios

- Facilita análise de defeitos.
- Suporta auditorias.
- Aumenta a confiabilidade dos testes.
- Permite reproduzir problemas encontrados.

Segundo **Cem Kaner**:

> "A evidência adequada reduz discussões subjetivas e direciona a equipe para fatos observáveis."

---

## Relação com o Processo de Teste

| Atividade | Uso da Evidência |
|------------|-----------------|
| Execução | Registro do resultado |
| Reporte de defeitos | Comprovação do problema |
| Auditoria | Demonstração de conformidade |
| Encerramento | Histórico da qualidade entregue |

As evidências constituem a prova objetiva de que os testes foram realizados e dos resultados obtidos.
