# Relatório de Execução de Testes

O **Relatório de Execução de Testes** é um artefato utilizado para registrar os resultados obtidos durante a execução dos casos de teste, fornecendo informações sobre a qualidade do produto e o andamento das atividades de teste.

Segundo o ISTQB, o relatório deve comunicar de forma clara o status dos testes, os defeitos encontrados e os riscos remanescentes, servindo como base para decisões relacionadas à liberação do software.

Conforme **Rex Black** (em *Managing the Testing Process*):

> "Os relatórios de teste transformam dados de execução em informações úteis para a tomada de decisão."

---

## Conceito Fundamental

O relatório de execução tem como objetivo responder perguntas como:

- Quantos testes foram executados?
- Quantos passaram ou falharam?
- Quais defeitos foram encontrados?
- Qual é o nível atual de risco do produto?

Seu foco principal é fornecer visibilidade sobre a qualidade do sistema e o progresso dos testes.

---

## Principais Informações de um Relatório

| Informação | Descrição |
|------------|-----------|
| Casos executados | Quantidade de testes realizados |
| Casos aprovados | Testes com resultado esperado |
| Casos reprovados | Testes com falhas identificadas |
| Defeitos encontrados | Problemas registrados durante a execução |
| Ambiente utilizado | Configuração onde os testes ocorreram |
| Data da execução | Momento em que os testes foram realizados |

---

## Exemplo Simplificado

| Métrica | Resultado |
|----------|------------|
| Casos planejados | 100 |
| Casos executados | 95 |
| Casos aprovados | 87 |
| Casos reprovados | 8 |
| Defeitos críticos | 1 |
| Defeitos médios | 4 |

---

## Benefícios

- Facilita a tomada de decisão.
- Permite acompanhar a evolução da qualidade.
- Auxilia auditorias e rastreabilidade.
- Apoia critérios de aprovação para entrega.

Segundo **Boris Beizer**:

> "Sem medição e comunicação dos resultados, a atividade de teste perde grande parte de seu valor para o negócio."

---

## Relação com Outros Artefatos

| Artefato | Finalidade |
|-----------|------------|
| Caso de Teste | Define o que será testado |
| Evidência de Teste | Comprova o resultado obtido |
| Relatório de Execução | Consolida os resultados da execução |

O relatório funciona como um resumo gerencial das atividades de teste realizadas.
