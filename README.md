# Roadmap de Estudos – QA Júnior

Este repositório documenta minha jornada de aprendizado como **QA (Quality Assurance) Júnior**.  
Aqui registro estudos teóricos, exercícios práticos, exemplos de testes, bugs reportados e testes automatizados.

O objetivo é desenvolver uma base sólida em qualidade de software, testes manuais, testes de API e introdução à automação.
