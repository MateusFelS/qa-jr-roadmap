# Lógica de Programação Básica

A **lógica de programação** é o conjunto de conceitos utilizados para desenvolver soluções de forma organizada e sequencial.

Ela constitui a base para a criação de algoritmos e programas, independentemente da linguagem de programação utilizada.

Segundo **Steve McConnell**, em *Code Complete*, compreender a lógica de programação é mais importante do que dominar uma linguagem específica, pois bons programas são construídos a partir de um raciocínio lógico bem estruturado.

---

# Conceito Fundamental

A lógica de programação consiste em definir uma sequência de instruções capazes de resolver um problema.

Essa sequência deve ser:

- Correta;
- Organizada;
- Finita;
- Executável.

O objetivo é transformar um problema em uma solução passo a passo.

---

# Algoritmo

Um **algoritmo** é uma sequência ordenada de instruções criada para resolver um problema ou executar uma tarefa.

Segundo **Thomas H. Cormen**, no livro *Introduction to Algorithms*, um algoritmo deve receber entradas, processá-las por meio de passos bem definidos e produzir um resultado esperado.

## Exemplos

- Calcular a média de duas notas.
- Validar um login.
- Ordenar uma lista de números.
- Emitir um relatório.

---

# Variáveis

Uma **variável** é um espaço reservado para armazenar dados durante a execução de um programa.

Seu valor pode ser alterado conforme a necessidade.

## Exemplos

- Nome do usuário.
- Idade.
- Saldo da conta.
- Quantidade de produtos.

---

# Operadores

Os operadores são utilizados para realizar cálculos e comparações.

## Operadores Aritméticos

- Soma (+)
- Subtração (-)
- Multiplicação (*)
- Divisão (/)

## Operadores Relacionais

- Igual (==)
- Diferente (!=)
- Maior (>)
- Menor (<)
- Maior ou igual (>=)
- Menor ou igual (<=)

## Operadores Lógicos

- AND (E)
- OR (OU)
- NOT (NÃO)

---

# Estruturas Condicionais

As estruturas condicionais permitem que o programa tome decisões com base em uma condição.

As mais utilizadas são:

- if
- else
- else if

## Exemplo

Se o usuário informar uma senha válida, o sistema permite o acesso; caso contrário, exibe uma mensagem de erro.

---

# Estruturas de Repetição

As estruturas de repetição executam um conjunto de instruções várias vezes.

As principais são:

- for
- while
- do...while

Elas são utilizadas quando uma ação precisa ser repetida até que determinada condição seja atendida.

---

# Fluxograma

O **fluxograma** representa graficamente a sequência de passos de um algoritmo.

Ele facilita a compreensão da lógica antes da implementação do código.

Segundo **Roger S. Pressman**, em *Engenharia de Software*, representações visuais ajudam na comunicação entre os membros da equipe e na documentação dos processos.

---

# Importância para o QA

Mesmo sem atuar como desenvolvedor, o profissional de QA utiliza conceitos de lógica de programação para:

- Compreender o funcionamento da aplicação;
- Criar cenários de teste;
- Interpretar regras de negócio;
- Escrever testes automatizados;
- Identificar possíveis falhas na lógica do sistema.
