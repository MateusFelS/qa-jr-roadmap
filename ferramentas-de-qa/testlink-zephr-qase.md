# TestLink, Zephyr e Qase

**TestLink**, **Zephyr** e **Qase** são ferramentas utilizadas para **gerenciamento de testes**.

Elas permitem criar, organizar, executar e acompanhar casos de teste, além de registrar os resultados das execuções.

Essas ferramentas auxiliam no planejamento dos testes e no controle da qualidade do software.

---

# Conceito Fundamental

As ferramentas de gerenciamento de testes são utilizadas para:

- Criar casos de teste;
- Organizar suítes de testes;
- Executar testes;
- Registrar resultados;
- Acompanhar a cobertura dos testes;
- Gerar relatórios.

Seu principal objetivo é centralizar todo o processo de testes em um único ambiente.

---

# TestLink

O **TestLink** é uma ferramenta **open source** voltada para o gerenciamento de testes.

Suas principais funcionalidades incluem:

- Cadastro de casos de teste;
- Organização em suítes de testes;
- Execução de testes;
- Registro dos resultados;
- Geração de relatórios.

É bastante utilizada em projetos que buscam uma solução gratuita.

---

# Zephyr

O **Zephyr** é uma ferramenta de gerenciamento de testes integrada ao **Jira**.

Entre suas principais funcionalidades estão:

- Criação de casos de teste;
- Planejamento de execuções;
- Registro dos resultados;
- Rastreabilidade entre requisitos, testes e bugs;
- Relatórios de execução.

Sua integração com o Jira facilita o acompanhamento das atividades de QA.

---

# Qase

O **Qase** é uma plataforma moderna para gerenciamento de testes.

Suas principais funcionalidades incluem:

- Criação de casos de teste;
- Organização de suítes;
- Planejamento de execuções;
- Registro dos resultados;
- Geração de relatórios;
- Integração com ferramentas como Jira e GitHub.

Possui uma interface intuitiva e recursos voltados para equipes ágeis.

---

# Comparação entre as Ferramentas

| Ferramenta | Principal característica |
|------------|--------------------------|
| TestLink | Open source e gratuito |
| Zephyr | Integração com o Jira |
| Qase | Interface moderna e diversas integrações |
