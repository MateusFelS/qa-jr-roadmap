# Git e GitHub

O **Git** é um sistema de **controle de versão**, enquanto o **GitHub** é uma plataforma para armazenar e compartilhar repositórios Git.

Essas ferramentas permitem que equipes trabalhem de forma colaborativa, mantendo o histórico das alterações realizadas no código.

---

# Conceito Fundamental

O **Git** é utilizado para:

- Controlar versões do código;
- Registrar alterações;
- Criar ramificações (branches);
- Unir alterações (merge);
- Permitir o trabalho colaborativo.

Já o **GitHub** permite:

- Armazenar repositórios na nuvem;
- Compartilhar projetos;
- Colaborar entre equipes;
- Gerenciar Pull Requests e Issues.

---

# Git

O **Git** registra todas as alterações feitas nos arquivos de um projeto.

Suas principais funcionalidades são:

- Controle de versões;
- Histórico de alterações;
- Criação de branches;
- Merge de alterações;
- Recuperação de versões anteriores.

---

# GitHub

O **GitHub** é uma plataforma baseada no Git que facilita a colaboração entre desenvolvedores.

Seus principais recursos incluem:

- Hospedagem de repositórios;
- Pull Requests;
- Issues;
- Revisão de código;
- Controle de acesso aos projetos.

---

# Principais Comandos do Git

Os comandos mais utilizados são:

- `git init` → inicializa um repositório.
- `git clone` → copia um repositório existente.
- `git add` → adiciona arquivos para versionamento.
- `git commit` → salva as alterações.
- `git push` → envia alterações para o repositório remoto.
- `git pull` → atualiza o repositório local.
- `git status` → exibe o estado dos arquivos.
- `git branch` → gerencia branches.

---

# Git x GitHub

| Git | GitHub |
|------|---------|
| Sistema de controle de versão | Plataforma de hospedagem de repositórios Git |
| Funciona localmente | Funciona na nuvem |
| Controla o histórico do código | Facilita o trabalho colaborativo |
