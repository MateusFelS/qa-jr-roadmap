# Inspeção de Elementos no Navegador

A **Inspeção de Elementos** é um recurso disponível nos navegadores modernos que permite visualizar e analisar a estrutura, o estilo e o comportamento de uma página web.

É uma ferramenta muito utilizada por profissionais de QA para identificar problemas e auxiliar na validação de aplicações.

---

# Conceito Fundamental

A Inspeção de Elementos permite:

- Visualizar o HTML da página;
- Analisar estilos CSS;
- Verificar atributos dos elementos;
- Identificar erros no navegador;
- Auxiliar na localização de elementos para automação de testes.

Na maioria dos navegadores, pode ser acessada pressionando **F12** ou clicando com o botão direito sobre um elemento e selecionando **Inspecionar**.

---

# Principais Recursos

Durante a inspeção é possível:

- Visualizar a estrutura HTML;
- Analisar estilos CSS aplicados;
- Identificar IDs, classes e atributos;
- Alterar temporariamente elementos da página;
- Verificar mensagens de erro no Console.

---

# Uso no QA

A Inspeção de Elementos auxilia o QA em diversas atividades, como:

- Validar informações exibidas na interface;
- Identificar elementos para automação de testes;
- Investigar problemas de layout;
- Analisar erros exibidos no Console;
- Verificar requisições e respostas na aba **Network**.

---

# Principais Abas das Ferramentas do Desenvolvedor

| Aba | Função |
|------|--------|
| **Elements** | Exibe a estrutura HTML e os estilos CSS da página. |
| **Console** | Mostra mensagens, erros e logs da aplicação. |
| **Network** | Exibe as requisições e respostas entre navegador e servidor. |
| **Application** | Permite visualizar cookies, Local Storage e Session Storage. |
